# Сәлем, мен Абылай Нұрланұлы

**IT инфрақұрылымда 10 жылдан астам тәжірибесі бар DevOps инженермін.** Бірнеше дата-орталықтағы
Kubernetes негізіндегі жоғары жүктемелі, ақауға төзімді платформаларды сүйемелдеймін,
Python және Go тілдерінде бэкенд жазамын.

Жақында біздің команда бүкіл виртуализация платформасын — **140-тан астам түйін және 1050-ге жуық ВМ** —
VMware-ден Proxmox VE-ге тоқтаусыз көшірді. [Толығырақ](about.md)

Бұл сайтта өзімнің пет-жобаларымды, талдауларымды және құжаттамамды жариялаймын.

## Немен айналысамын

- :material-server: **Инфрақұрылым** — bare metal, Proxmox VE, VMware, Kubernetes, дата-орталықтар арасындағы репликация

- :material-chart-line: **Мониторинг** — Grafana, VictoriaMetrics, Zabbix, ELK
- :material-shield-key: **Қауіпсіздік** — Vault арқылы құпияларды басқару
- :material-cloud: **Бұлттар** — AWS, Cloudflare, DigitalOcean
- :material-language-python: **Бэкенд** — Python (FastAPI, Django REST Framework), Go (Gin)

- :material-robot: **ЖИ құралдары** — эксплуатацияға арналған LLM негізіндегі көмекшілер
