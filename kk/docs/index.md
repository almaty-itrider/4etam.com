# Сәлем, мен Абылай Нұрланұлы

**DevOps инженермін**: bare metal, Proxmox және Kubernetes негізінде инфрақұрылым құрып, оны қолдаймын.
Күнделікті PostgreSQL + Patroni, Kafka және HashiCorp Vault-пен жұмыс істеймін, Python-да бэкенд жазамын.

Бұл сайтта өзімнің пет-жобаларымды, талдауларымды және құжаттамамды жариялаймын.

## Немен айналысамын

- :material-server: **Инфрақұрылым** — bare metal, Proxmox, виртуалды машиналар, Kubernetes
- :material-database: **Деректер платформалары** — Patroni негізіндегі тұрақты PostgreSQL, Kafka
- :material-shield-key: **Қауіпсіздік** — Vault арқылы құпияларды басқару
- :material-language-python: **Бэкенд** — Python, FastAPI, Django REST Framework
- :material-robot: **ЖИ құралдары** — эксплуатацияға арналған LLM негізіндегі көмекшілер
