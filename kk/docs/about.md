# Мен туралы

Мен DevOps инженермін. Күнімнің көп бөлігі серверлерде өтеді: Proxmox-тағы Kubernetes пен виртуалды машиналар,
PostgreSQL/Patroni кластерлері, Kafka және Vault, барлық орталардағы жаңартулар.
Бұған дейін Python-да бэкенд жаздым (DRF, FastAPI).

Пет-жобаларды күнделікті қолданатын құралдарды тереңірек түсіну үшін
және ЖИ инфрақұрылыммен жұмысты қалай жылдамырақ әрі қауіпсіз ете алатынын көру үшін жасаймын.
